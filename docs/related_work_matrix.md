# Related Work Matrix: Semantic Validation

Scope: post-extraction semantic validation, false-support reduction, evidence attribution, factual consistency scoring, NLI robustness, claim verification, and RAG/citation groundedness benchmarks that can justify or extend the `supported` / `contradicted` / `insufficient` validation protocol.

Selection note: sources were selected from primary venues and project pages current as of 2026-06-24. Priority is given to work that either matches this repository's datasets, explains lexical/NLI failure modes, or offers a concrete backend or metric that can be compared against the current validators.

## Immediate takeaways

- The strongest positioning is not "NLI beats lexical baselines"; it is "semantic validation makes false support explicit, and current generic NLI is only one imperfect backend."
- The closest direct anchors are AttributionBench, SciFact, QASPER, AIS, ALCE, RAGTruth, GaRAGe, and CAQA.
- The most useful methodological imports are HANS/NLI stress slices, SummaC-style NLI aggregation, AlignScore/MiniCheck as official semantic backends, and citation-quality dimensions from ALCE/CiteEval.
- A defensible next experiment is a small stress-suite table that reports false_support_rate, support_recall, and support_f1 by phenomenon: lexical overlap, negation, numeric/value mismatch, entity mismatch, insufficient context, and partially supported evidence.
