## Обзор проекта

Проект представляет собой Telegram-бота с ИИ-системой, которая помогает пользователю составить рацион на день.

## Build/test команды

Для работы с зависимостями и модулями проекта используется `uv`.

Если не хватает каких-то зависимостей проси у меня их установить.

Не запускай тесты, если нужен их вывод, то пиши команды для запуска и попроси их результат у меня.

## Настройки проекта

- *Язык программирования*: Python 3.12
- *Инструмент обработки данных*: Pandas
- *Менеджер зависимостей*: UV

## Код‑стайл/линтеры

1. Не использовать typing.
2. Код должен быть компактым, без helper-функций.
3. Никаких пустых dict/tuple/list для сложных структур: если структура не тривиальная - описываем в structures.py (DTO/контракты) или constants.py.
4. Для каждого блока кода писать короткий комментарий, что делает код.
5. Функции должны быть написаны с типизацией параметров на вход и на выход.
6. Docstring формат везде одинаковый:
    - Для функций:

```python
Короткое описание, что делает функция.

Parameters:
    название (тип): Описание. По умолчанию: значение.
    название (тип): Описание.

Returns:
    тип: Описание.

Fallbacks:
    Описание.
```

    - Для классов:

```python
Короткое описание класса.

Attributes:
    название (тип): Описание. По умолчанию: значение.
    название (тип): Описание.

Fallbacks:
    Описание.
```

## Кодировка и редактирование файлов на Windows

- При работе на Windows запрещено изменять текстовые файлы через shell redirection и shell-generated output.

- Запрещены способы записи, зависящие от кодировки терминала/консоли:
    - `echo ... > file`
    - `echo ... >> file`
    - `printf ...`
    - heredoc / here-string с записью в файл
    - `Out-File`
    - `Set-Content`
    - любая другая запись файла через shell, зависящая от encoding консоли

- Текстовые файлы, особенно с кириллицей, разрешено изменять только:
    - через patch/editor tool
    - или через Python c явным `encoding="utf-8"`

- Безопасный паттерн записи:

```python
from pathlib import Path

path = Path("file.md")
text = path.read_text(encoding="utf-8")
text = text.replace("старое", "новое")
path.write_text(text, encoding="utf-8", newline="\n")
```
